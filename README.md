VetLink — iOS-приложение для ветеринарной клиники, позволяющее пользователям просматривать информацию о врачах и управлять записями.
Основной функционал:
  - Экран "Врачи": отображение списка ветеринарных врачей с фотографиями, именами и специализациями. При нажатии открывается детальная информация (опыт, рейтинг, описание, цена консультации).
  - Экран "Записи": UI для просмотра записей (в текущей версии только интерфейс).
  - Экран "Профиль": настройки приложения (Privacy Policy, Terms of Use, Rate Us, How to Use).
  - Поддержка темной/светлой темы: автоматическая адаптация к системной теме iOS.

Применяемые решения
  1. Асинхронная работа с сетью
    Использование Completion Handlers для асинхронных операций
    Все сетевые запросы выполняются в фоновых потоках
    Обновление UI происходит на главном потоке через DispatchQueue.main.async
  2. Управление состоянием
    Сохранение выбранной вкладки в UserDefaults для восстановления при следующем запуске
    Использование weak references для предотвращения retain cycles
  3. Загрузка изображений
    Асинхронная загрузка через URLSession
    Использование системного кэширования URLSession.shared
    Плейсхолдеры при ошибках загрузки
  4. Адаптация к теме
    Использование системных цветов (.systemBackground, .label, .secondaryLabel)
    Автоматическая адаптация UI к системной теме iOS без дополнительного кода

Используемые библиотеки
  1. Supabase Swift SDK
    Использование: Backend-as-a-Service для работы с базой данных и хранилищем файлов.
    Почему выбрана:
      Готовая инфраструктура (PostgreSQL, Storage, Auth)
      Нативный Swift SDK с поддержкой async/await
      Простая интеграция и быстрый старт
      Бесплатный тариф для разработки
    Где используется:
      Загрузка списка врачей из базы данных
      Хранение и загрузка фотографий врачей из Supabase Storage

  2. Нативные фреймворки iOS
    UIKit: UI компоненты
    Foundation: базовая функциональность
    URLSession: сетевые запросы и загрузка изображений

Архитектура
  Приложение использует архитектурный паттерн VIPER (View, Interactor, Presenter, Entity, Router).
